# 공개 전 점검표

체크가 안 끝난 항목이 있으면 공개하지 않습니다. 특히 1장은 **하나라도 남으면 공개 금지**예요.

---

## 1. 공개를 막는 것

법적 위험이나 되돌릴 수 없는 사고로 이어지는 항목입니다.

### 파일 해시

| | 항목 | 왜 |
|---|---|---|
| ☐ | WAI v17 원본 SHA-256 재확인 | 받아온 파일이 바뀌었는지 알 유일한 수단 |
| ☐ | Anima 3개 파일 SHA-256 등록 | 위와 동일 |
| ☐ | RealESRGAN_x2plus SHA-256 등록 | 위와 동일 |
| ☐ | tokenizer JSON 2개 SHA-256 등록 | 위와 동일 |

해시가 `null`이면 설치 스크립트가 검사를 못 합니다. 조용히 다른 파일이 깔려도 모릅니다.

### 라이선스

| | 항목 |
|---|---|
| ☐ | WAI · Anima · LoRA 5개의 **무료 공개 서빙** 조건 확인 |
| ☐ | 재호스팅 허용 여부 확인 |

무료로 서비스해도 조건이 붙는 모델이 있습니다. `licenseReview: required`인 항목은 확인이 끝나기 전에 올리지 마세요.

### 검열

| | 항목 |
|---|---|
| ☑ | 검열 Worker 배포 및 `IMAGE_MODERATION` 바인딩 연결 |
| ☑ | 규칙 엔진 테스트 18개 통과 |
| ☑ | I2I 잠금 (이미지 판정 수단이 생길 때까지) |
| ☐ | 소유자가 기본 금지어 목록 검토 |
| ☐ | 실존 인물 목록 보강 — 지금은 지시어 몇 개뿐입니다 |
| ☐ | 시험 판정으로 오탐 확인 (자주 쓰는 프롬프트 20개 정도) |

검열은 **규칙 기반**입니다. 자연어로 풀어 쓴 우회에는 약하니, 공개 후 로그를 보며 목록을 늘려야 합니다.

**I2I를 열 때는** 원본 이미지 판정을 먼저 붙이세요. 텍스트만 보면 이미지로 그냥 우회됩니다.

## 2. 기능 — 끝난 것

| | 항목 |
|---|---|
| ☑ | 모델 2개 × 비율 3개 워크플로우 생성 |
| ☑ | 모델별 sampler·scheduler·steps·CFG 서버 검증 |
| ☑ | 10자리 시드 검증과 암호학적 무작위 생성 |
| ☑ | 허용목록 LoRA 최대 3개, 트리거 자동 삽입 |
| ☑ | I2I on/off, denoise, 자르기 방식, 입력 형식·크기 검사 |
| ☑ | Real-ESRGAN 2× on/off |
| ☑ | PNG·WebP 선택 |
| ☑ | 일 50장 · 주 250장, I2I 1.5장 정수 회계 |
| ☑ | 실행 1 · 대기 4, FIFO, 리스 만료 복구 |
| ☑ | R2 비공개 결과 전달 |
| ☑ | 30일 이미지 · 7일 기록 · 15/10 보관 예외 |
| ☑ | 계정당 프롬프트 프리셋 50개 |
| ☑ | 관리자용 GPU·큐 상태 API |
| ☑ | `admin.html` 이미지 상태 카드 |
| ☑ | 생성 기록·갤러리 화면 |
| ☑ | 서비스 전체 누적 현황 (1·3·7·30일·전체) |

### 아직 없는 것

| | 항목 | 비고 |
|---|---|---|
| ☐ | `usage.html` 이미지 할당량 카드 | `/api/image/quota` 그대로 쓰면 됨 |
| ☐ | 한 번에 여러 장 생성 | 정책값은 1장으로 내려둠 |
| ☐ | I2I | 이미지 판정이 생기면 |

## 3. 보안

| | 항목 | 확인 방법 |
|---|---|---|
| ☐ | ComfyUI 8188 외부 차단 | 컨테이너 밖에서 접속 시도 |
| ☐ | 토큰 두 개 분리, 32바이트 이상 | `WORKER_API_TOKEN` ≠ `GATEWAY_TOKEN` |
| ☐ | 오류 응답에 예외 message·stack 없음 | 일부러 실패시켜 본문 확인 |
| ☐ | R2 버킷 공개 접근 차단 | 버킷 설정 |
| ☐ | 검열 장애 시 fail-closed | 바인딩 뺀 채로 생성 시도 → 503 |
| ☐ | 검열 Worker에 라우트 없음 | 대시보드 Domains & Routes 비어 있는지 |
| ☐ | 10MB · 4K 초과, 위조 MIME 업로드 거부 | 직접 시도 |
| ☐ | 임의 `class_type` · 파일명 · 노드 ID 주입 거부 | 직접 시도 |

가장 위험한 건 첫 줄입니다. **8188이 열리면 이 문서의 모든 제한이 통째로 우회됩니다.**
